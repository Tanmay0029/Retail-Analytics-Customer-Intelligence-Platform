# Dashboard 2: Customer Insights & Retention

## 🎯 Goal Description
Showcase advanced Data Science capabilities by implementing RFM (Recency, Frequency, Monetary) Segmentation and Cohort Retention Analysis to track customer loyalty over time.

## 🧮 DAX Measures
Because we handled the heavy lifting for RFM and Cohorts in SQL, our DAX for this dashboard is incredibly lean and efficient.

**1. Retained Customers**
*Why it was needed:* Used specifically inside the Heatmap Matrix to count how many distinct customers came back in Month 1, Month 2, etc. We must ignore anonymous customers (`-1`) because you cannot track the retention of a ghost.
```dax
Retained Customers = 
CALCULATE(
    DISTINCTCOUNT('gold fact_sales'[Customer_key]),
    'gold fact_sales'[Is_cancelled] = False,
    'gold dim_customer'[Customer_id] <> -1
)
```

**2. Customer Count**
*Why it was needed:* To plot the distribution of customers across the different RFM segments.
```dax
Customer Count = 
CALCULATE(
    COUNTROWS('gold dim_customer'),
    'gold dim_customer'[Customer_id] <> -1
)
```

**3. Registered vs Anonymous Revenue Splits**
*Why it was needed:* To show Marketing exactly how much money is generated by guest checkouts (which cannot be retargeted via email).
```dax
Anonymous Revenue = 
CALCULATE(
    [Total Revenue],
    'gold dim_customer'[Customer_id] = -1
)

Registered Revenue = 
CALCULATE(
    [Total Revenue],
    'gold dim_customer'[Customer_id] <> -1
)
```

## 🧠 Key Technical Learnings & Discussions
* **Pushing Math to SQL:** Instead of writing agonizingly slow DAX for RFM and Cohorts, we wrote a physical SQL script (`02_advanced_analytics_rfm_cohort.sql`) to calculate `Recency`, `Frequency`, `Monetary`, and `Cohort_Month_Offset` at the database level. Power BI is used purely for visualization.
* **The "Summing ID" Trap:** Power BI automatically tried to `SUM()` the `Customer_id` column, resulting in garbage numbers like "14,230,111". We fixed this by setting the column behavior to "Don't summarize" in the visual pane, forcing Power BI to display individual rows for our VIP table.
* **Gross vs Net RFM Scores:** We noticed that raw SSMS aggregations returned lower revenue numbers than our RFM calculation. This is because RFM filters *out* cancellations (`Is_cancelled = 0`) to measure a customer's total "Gross Successful Spend capacity", while a raw SUM includes negative return values.
* **Understanding Cohort Offsets:** We discussed why `Cohort_Month_Offset` is `0` for the acquisition month, and why it is `NULL` for anonymous checkouts. Power BI automatically ignores the NULLs, keeping the matrix clean.
